# Lesson 01 · Your First Program

▶ Video: https://youtu.be/cumsF-7xYpk

**In this lesson:** you make Python show things on the screen, and finish with the title screen
of a tiny game: *Rain Runner*.

## You learn

- `print()` and your first `"Hello, World!"`
- strings, numbers and comments (`#`)
- repeating a string to draw borders: `"=" * 40`
- multi-line strings (`"""..."""`) for ASCII art
- special characters: `\n` (new line) and `\t` (tab)

## Where games use this

Every game server writes lines like these all day: *"player joined"*, *"item saved"*, *"server started"*.
They are called **logs**, and they are how developers see what is happening inside an online game.
It all starts with `print()`.

## Run it

```
python main.py
```
